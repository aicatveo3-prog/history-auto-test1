# 편집 기준과 참고 자료

100개 주제에 상황·배경·작동 원리·결과를 연결하고 반복 요약과 추상적인 마무리를 줄였습니다. 넓은 주제는 핵심 흐름을 골라 설명하며 세부 원문은 사이트에서 따로 볼 수 있습니다.

세 비교 시안은 전체 편집의 기준입니다. 인물형과 문화형은 기존 상위 주제에서 범위를 좁힌 별도 편이며 대동법은 승인된 압축 시안 본문을 사용했습니다. 실제 발언을 창작해 사료처럼 인용하지 않습니다. 검토는 작성자 자체 검토이며 전문가 검수나 낭독 시간 측정은 아닙니다.
